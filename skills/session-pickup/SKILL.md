# Session Pickup

Resume from a handoff with minimal re-discovery.

## Steps
1. Read handoff: goals, decisions, open loops, next actions.
2. Confirm nothing critical is stale (paths, APIs, decisions reversed).
3. Pick the top open loop; state the first action.
4. Ask only for missing blockers — do not re-ask solved questions.
5. Update continuity notes as you go.
