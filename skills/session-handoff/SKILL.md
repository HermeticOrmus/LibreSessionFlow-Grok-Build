# Session Handoff

Produce a handoff package others can pick up cold.

## Steps
1. Restate goal and current status (done / blocked / next).
2. List decisions made and why (1 line each).
3. List open loops with owner and blocker.
4. List files/paths touched and why.
5. Next 3 concrete actions.
6. Flag unknowns — do not invent state.
