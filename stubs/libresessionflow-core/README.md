# libresessionflow-core (Grok plugin stub)

v0 record, superseded in v1.0.0. This folder had no manifest, so `grok plugin install` took it as an unversioned plugin holding only a copy of the stub orchestrator. The melted skills now ship as [plugins/libre-sessionflow-grok](../../plugins/libre-sessionflow-grok/). The text below describes the v0 layout.

Bundles core libresessionflow skills for install-from-path.

This plugin directory is still a **stub**. Canonical melted bodies live under repo `skills/` (`session-handoff`, `session-pickup`, `session-absorb`). Copy or symlink those into this plugin's `skills/` when packaging.

Do not treat this folder as melted inventory. See [docs/DEPTH_MATRIX.md](../../docs/DEPTH_MATRIX.md).
