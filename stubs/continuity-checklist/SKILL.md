Stub, not a playbook. Real depth: the [`close`](https://github.com/HermeticOrmus/LibreSessionFlow-Claude-Code/tree/main/plugins/close) plugin from LibreSessionFlow-Claude-Code. Install it from this marketplace: `grok plugin install close@libre-sessionflow-grok --trust`.

Smoke checks before ending a session.

## Checks
- [ ] Goal status written
- [ ] Decisions captured
- [ ] Open loops listed with blockers
