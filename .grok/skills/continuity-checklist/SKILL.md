# Continuity Checklist

Smoke checks before ending a session.

## Checks
- [ ] Goal status written
- [ ] Decisions captured
- [ ] Open loops listed with blockers
- [ ] Next 3 actions named
- [ ] Secrets not left in notes
- [ ] Handoff or digest saved where the next turn can find it
