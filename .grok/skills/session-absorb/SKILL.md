# Session Absorb

Integrate prior state into the active turn.

## Steps
1. Collect prior digests / handoffs / key messages.
2. Deduplicate goals and decisions.
3. Mark conflicts explicitly (do not silently overwrite).
4. Produce a single absorbed context block.
5. State what was dropped and why.
